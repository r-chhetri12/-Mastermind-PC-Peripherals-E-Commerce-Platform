# 🧠 Mastermind — PC & Peripherals E-Commerce Platform

> Your one-stop destination for PCs, Laptops, Gaming Peripherals & Accessories.

---

## 📌 About the Project

**Mastermind** is a full-stack e-commerce web application built for a tech retail company specializing in high-performance computing products. The platform offers customers a seamless shopping experience — from browsing products to placing orders and tracking deliveries — while giving administrators powerful tools to manage inventory, products, and business analytics.

---

## 🛍️ Products We Sell

- 🖥️ Desktop PCs
- 💻 Laptops
- 🖱️ Mice
- 🎮 Graphic Cards (GPUs)
- ⌨️ Keyboards
- 🎧 Headphones

---

## 🌐 Pages & Features

### Customer-Facing Pages

| Page | Description |
|------|-------------|
| **Home** | Landing page showcasing featured products, offers, and categories |
| **About** | Company story, mission, and team details |
| **Contact** | Inquiry form and contact information |
| **Products** | Browse, filter, and search all available products |
| **My Orders** | View past orders, invoices, and live shipment status |
| **Checkout** | Secure checkout with Razorpay payment integration |

### Admin Panel

| Feature | Description |
|---------|-------------|
| **Admin Login** | Secure login portal for administrators |
| **Dashboard** | Real-time business stats — revenue, orders, customers, and inventory overview |
| **Product Management** | Add, edit, view, and delete products (Full CRUD) |
| **Inventory Management** | Track and update stock levels across all categories |

---

## 💳 Payment Integration

Integrated with **Razorpay** for secure and seamless payment processing at checkout, supporting multiple payment methods including UPI, cards, and net banking.

---

## 🗄️ Database Integration

- User registration and login data is stored securely in the database
- Customer order history and invoice records are persisted and retrievable
- Admin CRUD operations directly reflect in real-time on the database
- Shipment and order status updates are tracked per customer
